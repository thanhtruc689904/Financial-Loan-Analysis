# 💰 Financial Loan Data Analyst Portfolio Project

This project represents a complete, end-to-end data analytics workflow, simulating real-world financial analysis in a lending environment. It demonstrates how raw loan data can be transformed into meaningful insights to support risk management and data-driven decision-making.

---

## 📌 This project is ideal for:
- Data Analyst interns building a strong portfolio  
- 📚 Learners practicing Python, SQL, and Power BI  
- 💼 Preparing for Data Analyst / Financial Analyst interviews  

---

## 📊 Project Overview

The objective of this project is to analyze loan performance and extract actionable insights related to portfolio quality, customer behavior, and financial risk.

## 🔹 Data Preparation & EDA (Python)
- Cleaned and transformed loan dataset  
- Handled missing values and inconsistent data  
- Created time-based features for analysis  

## 🔹 Data Analysis (SQL)
- Calculated key KPIs:
  - Total Loan Applications  
  - Total Funded Amount  
  - Total Received Amount  
  - Average Interest Rate  
  - Average Debt-to-Income (DTI)  
- Segmented loans into **Good vs Bad loans**  
- Analyzed trends over time  

## 🔹 Data Visualization (Power BI)
- Built interactive dashboard  
- Visualized loan trends, repayment performance, and customer segments  
- Highlighted portfolio quality and risk distribution  

## 🔹 Reporting & Insights
- Summarized key findings  
- Provided business insights for loan risk management

## 📈 Key Insights

* A significant portion of loans are classified as **good loans**, contributing stable revenue
* Bad loans (defaults) negatively impact overall portfolio performance
* Higher interest rates are often associated with higher-risk customers
* Loan performance varies across customer segments and time periods

---

## 💡 Solution & Recommendations

* **Improve credit risk assessment:**
  Strengthen screening criteria to reduce the proportion of bad loans

* **Optimize interest rate strategy:**
  Adjust interest rates based on customer risk profiles to balance risk and return

* **Monitor high-risk segments:**
  Identify and closely track customers with high DTI or poor repayment history

* **Enhance customer segmentation:**
  Use data to create targeted loan offers and improve approval strategies

* **Early risk detection:**
  Implement monitoring systems to detect potential defaults early
